
## General Steps for Each Assignment

1. **Download the assignment:**
    - Download the provided ZIP file for the assignment and extract it to your working directory.

2. **Open the file:**
    - Use VS Code to open and edit your `.cpp` file.

    - If you haven't installed VS Code yet, follow the instructions in the [VS Code Installation README](../../../../vs-code-installation.md).

3. **Compile:**
    ```powershell
    g++ -o program <yourfile.cpp>
    ```
    - This command will compile your C++ file using `g++` and create an executable named `program`.

    - **Note:** If you receive an error that `g++` is not recognized, refer to the [C++ installation instructions](../../../../cpp-installation.md) to set up your environment.

4. **Run:**
    ```powershell
    ./program
    ```
    - This will execute your compiled C++ program.

5. **Check Style:**
    - Review your code for style and formatting according to the guidelines.

6. **Submit:**
    - Submit your `.cpp` file in the assignment in Google Classroom.
