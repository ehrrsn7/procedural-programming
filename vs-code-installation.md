# Installing Visual Studio Code

Students do **not** have admin access on their machines and do **not** have access to GitHub. The simplest way to install VS Code is via the Microsoft Store, which does **not** require admin rights.

## Option 1: Microsoft Store (Recommended)

1. Open the **Microsoft Store** app.
2. Search for **Visual Studio Code**.

- Or, [click here to open Visual Studio Code in the Microsoft Store](https://apps.microsoft.com/detail/XP9KHM4BK9FZ7Q?hl=en-US&gl=US&ocid=pdpshare).

[![alt text](image.png)](https://apps.microsoft.com/detail/XP9KHM4BK9FZ7Q?hl=en-US&gl=US&ocid=pdpshare)

3. Click **Install**.

This will install the user version of VS Code without needing admin privileges.

## Option 2: VS Code Website

If you prefer, you can download VS Code directly from the [official website](https://code.visualstudio.com/Download):

1. Go to the [VS Code download page](https://code.visualstudio.com/Download).
2. Download the **User Installer** for Windows.
3. Run the installer and follow the prompts.

To add the "Open with Code" option to the Windows Explorer context menu:

- During installation, check the box for **"Add to PATH"** and **"Add 'Open with Code' action to Windows Explorer file context menu"**.

> **Note:** This option may require additional permissions. If you encounter issues, use the Microsoft Store method above.
